# Education Enrollment Forecasting & Early Risk Detection

A synthetic analytics project demonstrating how forecasting and early-warning indicators can support enrollment planning and executive decision-making in higher education.

## Business Problem

Education organizations make enrollment, staffing, budgeting, and resource-allocation decisions before final enrollment is known. Traditional reporting can show what has already happened, but leaders also need forward-looking insight into where enrollment is likely to finish and whether emerging changes in the enrollment funnel create material risk.

This project develops a synthetic enrollment environment to explore three questions:

1. What is the expected final enrollment based on currently available information?
2. How accurately can enrollment be forecast before the admissions cycle closes?
3. Which changes in the enrollment funnel provide the earliest warning that actual enrollment may deviate from plan?

## Analytical Approach

The project uses fully synthetic data representing multiple historical enrollment cycles. The analysis combines:

- exploratory analysis of enrollment-funnel behavior
- time-aware forecasting and model validation
- comparison with simple baseline forecasts
- early-warning indicators for emerging enrollment risk
- executive-oriented interpretation of model outputs

## Data

All data in this repository are synthetic and were created solely for demonstration purposes. No institutional, student, client, or proprietary data are used.
